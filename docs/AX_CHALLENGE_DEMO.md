# 데모 영상 녹화 가이드 — 메모비서

목표: 2분 안팎. **입력과 결과가 화면에 함께 보이도록** 실제 조작을 녹화합니다.
사이트: https://memo-assistant.ggyaal.workers.dev/ (시크릿 창 권장 — 로그인 없이 동작함을 보여줌)

## 녹화 전 준비
- [ ] Chrome 시크릿 창, 창 폭 1280px 이상(오른쪽 사이드 패널이 보이도록)
- [ ] 마이크 연결, 조용한 곳(주변 사람 목소리 녹음 금지)
- [ ] 화면에 개인정보·북마크·다른 탭·알림이 보이지 않게 정리
- [ ] 입력에는 **가상 내용만** 사용(모든 메모가 공개됨)
- [ ] 화면 상단 "오늘 AI 사용 N / 150회"가 한도에 가깝지 않은지 확인

## 녹화 순서 (권장 대사 포함)

| # | 화면 조작 | 보여줄 것 | 예상 결과 (2026-11-14 운영 실측) |
|---|---|---|---|
| 1 | 접속 → 공개 안내 문구 가리키기 | 공개 데모·개인정보 금지 고지 | 노란 안내 박스 |
| 2 | 닉네임 입력 → 시작하기 | 로그인 없이 시작 | 입력 카드 표시 |
| 3 | `내일 오후 3시에 팀 회의 준비해야 해` 입력 → **AI로 정리하기** | 10–30초 정리 | 할 일 "팀 회의 준비", 📅 내일 오후 3:00, 알림 추천, 중요도 |
| 4 | `퇴근할 때 우유 사고, 주말에는 방 청소해야겠다` | **한 문장 → 2개 분리** | "우유 사기", "주말 방 청소" (날짜를 지어내지 않고 "정확한 일시 없음") |
| 5 | 🎙️ **음성으로 입력** → 안내 확인 → 녹음 → 말하기 → 다시 눌러 종료 | 녹음 중 표시·초 카운트, 변환 후 입력창에 글 | 말한 문장이 입력창에 들어감 → 확인 후 **AI로 정리하기** |
| 6 | 오른쪽 **일정 우선순위**에서 항목을 끌어 순서 변경 → 새로고침 | 순서 유지 | 바꾼 순서 그대로, "직접 정렬됨" |
| 7 | 메모 카드 체크박스 클릭 → 새로고침 → 다시 해제 | 취소선·유지·복구 | 체크 시 취소선, 해제 시 원래대로 |
| 8 | **지나버린 일** 패널 소개 | 기한 지난 미완료만 표시, 삭제 버튼 | "N일 지남" 배지 |
| 9 | (선택) `카드 1234-5678-9012-3456` 입력 | 개인정보 차단 | 경고 + 전송 버튼 비활성 |
| 10 | (선택) `다음에 시간 되면 병원 예약해야지` | 한계/모호성 처리 | 기한 없음, 중요도 낮음 |

> 6–8번은 **모든 방문자에게 공유되는 변경**입니다. 녹화 후 직접 만든 테스트 메모만 원래대로(체크 해제 등) 돌려 두세요. 다른 사람의 메모는 삭제하지 마세요.

## 실패 시 대처 (녹화 중 발생하면 그대로 보여줘도 좋음)
- "AI 응답이 너무 오래 걸립니다"/"정리하지 못했습니다" → 입력 글이 남아 있음을 보여주고 **다시 시도**.
- 마이크 권한 팝업에서 차단했다면 → 주소창 자물쇠 아이콘 → 마이크 허용 후 새로고침.
- "오늘 무료 사용량을 모두 썼습니다" → 한국 시간 오전 9시 이후 다시 녹화.
